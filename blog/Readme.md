# 梦飞 Blog

梦飞网络导航的 **Log / 教程子站**：日常、学习、运维、资讯、编程五个方向的记录与教程。

零框架、零构建的纯静态站，**整个目录自包含**——单独拷走 `blog/` 一个文件夹即可部署，不依赖主站任何文件。

## 目录结构

```
blog/
├── index.html       文章列表（hero 简介区 + 一行一条的文章列表）
├── css/style.css    全站共享样式（一个文件）
├── js/stars.js      星空 canvas 背景（可选，删除后页面照常）
├── icon/            favicon / apple-touch-icon / Tux 头像
├── posts/           一篇文章一个 HTML（日期-标题拼音.html，天然按时间排序）
└── Readme.md        本文件
```

## 视觉方案

- 与主站导航页同一套浅色星空 + 毛玻璃主题：页面底色三段渐变、`canvas` 呼吸星点、`backdrop-filter` 玻璃面板
- 颜色全部走 `:root` CSS 变量；文章分类用 `data-cat` 注入强调色 `--acc`：

  | 分类 | 强调色 |
  |---|---|
  | 日常 | 粉 `#f472b6` |
  | 学习 | 紫 `#a78bfa` |
  | 运维 | 黄 `#fbbf24` |
  | 资讯 | 蓝 `#38bdf8` |
  | 编程 | 绿 `#34d399` |

- 列表每条两行：首行「分类圆点 + 标题 + 日期」、次行摘要（超长省略）；标签文字统一黑色，分类识别靠圆点色
- 响应式：`≤640px` 徽章回退文档流居中；`≤560px` 收紧内边距
- 无障碍：正文对比度 ≥ AA，系统「减弱动态效果」时动画全部关闭、星空只画一帧

## 发新文章

1. 复制 `posts/` 里任意一篇文章，文件名改为 `日期-标题拼音.html`
2. 修改 `<title>`、`description`、`data-cat`、标题、日期、正文
3. 在 `index.html` 列表 `.grid` **顶部**加一张卡片（保持最新在前）：

```html
<a class="card" data-cat="日常" href="posts/xxx.html">
  <span class="tag"><i></i>日常</span>
  <h3>文章标题</h3>
  <p>一句话摘要。</p>
  <time>2026-11-25</time>
</a>
```

## 部署

- **GitHub Pages**：推到仓库（可放 `/blog` 子路径或独立仓库根目录），开 Pages 即可
- **NAS / 软路由**：整目录丢进 Web 根目录（飞牛 fnOS、iStoreOS 均自带）
- **本地预览**：`python3 -m http.server 8000`

页面内全部使用相对路径（`css/`、`js/`、`icon/`、`../icon/` 等仅在子站内互指），迁到任何路径、任何主机都不需要改代码。
