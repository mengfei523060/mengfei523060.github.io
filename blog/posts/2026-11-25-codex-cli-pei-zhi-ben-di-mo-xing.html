Codex CLI 配置本地大模型：config.toml 与 .env

编程2026-11-25

以 0.172.0 实测，只需要改两份文件，各添加几行本地 API 参数。

1. config.toml

编辑 ~/.codex/config.toml，添加：

# ~/.codex/config.toml
model = "qwen3-30b"                      # 与服务端 /v1/models 返回的 id 一致
model_provider = "local"

[model_providers.local]
name = "本地模型"
base_url = "http://127.0.0.1:1234/v1"    # LM Studio 默认 1234；Ollama 改为 11434
env_key = "LOCAL_API_KEY"                # API Key 所在的环境变量名
wire_api = "responses"                   # 0.172 起只支持 responses（chat 已移除）

2. .env

项目根目录（或家目录）建 .env，写入 env_key 指向的变量：

# .env
LOCAL_API_KEY=lm-studio                  # LM Studio / Ollama 不校验 Key，非空即可

Codex 不自动读取 .env，跑之前把它导入环境变量：

set -a; source .env; set +a              # 或交给 direnv 自动加载
生效检查：codex 启动后 /status 应显示 model: qwen3-30b、provider: local；报 wire_api = "chat" is no longer supported 就把 wire_api 改成 "responses"。
