教程：搭一个纯静态的日志站

编程2026-11-25

这个 Blog 站本身就是一个现成例子：没有任何框架、没有构建步骤，四个部分就能跑。这篇教程带你从零搭一遍。

1. 目录结构

blog/
├── index.html     列表页：hero + 文章卡片网格
├── css/style.css  全站共享样式（一个文件）
├── js/stars.js    星空 canvas 背景（可选，不要可删）
├── icon/          favicon 与头像（自包含）
└── posts/
    └── 2026-11-25-xxx.html   一篇文章一个文件

文章文件名建议 日期-标题拼音.html，天然按时间排序，也方便以后迁移。

2. 列表页

列表页就是一张张卡片，每张卡片链接到 posts/ 下的文章：

<a class="card" data-cat="日常" href="posts/xxx.html">
  <span class="tag"><i></i>日常</span>
  <h3>文章标题</h3>
  <p>一句话摘要。</p>
  <div class="row2"><time>2026-11-25</time></div>
</a>

data-cat 决定这张卡片的强调色（日常粉 / 学习紫 / 运维黄 / 资讯蓝 / 编程绿），CSS 里一行 [data-cat="xx"] { --acc:#xxx } 就够了。

3. 发新文章

  1. 复制任意一篇旧文章到 posts/，改文件名；
  2. 改 <title>、description、data-cat、标题、日期、正文；
  3. 在 index.html 的 .grid 里加一张卡片（放最前面即最新）。

4. 部署

本地双击 index.html 就能看。挂上网络任选其一：

  • GitHub Pages —— 推到仓库，Settings 里开 Pages，免费；
  • NAS / 软路由 —— 把 blog/ 目录丢进 Web 根目录（飞牛 fnOS、iStoreOS 都自带）；
  • 临时预览：python3 -m http.server 8000。
注意：站点公共资源（favicon、头像等）已内置在 blog/icon/ 里，列表页用 icon/、文章页用 ../icon/ 相对路径引用——整个 blog/ 目录自包含，单独拖到 GitHub Pages、NAS 或任意静态托管都能直接跑，不需要再带上其他文件。
