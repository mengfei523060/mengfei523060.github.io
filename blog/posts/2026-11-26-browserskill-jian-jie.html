BrowserSkill：让 Agent 接管你已登录的浏览器

编程2026-11-26

BrowserSkill（命令叫 bsk）是腾讯开源的浏览器自动化技能，解决的是老问题：Agent 操作浏览器要么起一个全新的无头浏览器，所有站点重新登录一遍；要么导出 cookie 喂给脚本，等于把凭据交出去。bsk 的思路是直接驱动你日常在用的 Chromium 浏览器——登录态天然就在那，不用搬运。

它由三部分组成

  • bsk CLI + 本地守护进程：命令入口，daemon 负责会话管理，普通命令会自动拉起它；
  • 浏览器扩展：Chrome 应用商店 / Edge 加载项装一个，浏览器就接上了 daemon；
  • browser-skill 技能：一份 SKILL.md 加十几篇参考文档，教 Agent 怎么调 CLI；支持 MCP 的环境还能直接注册 bsk_* 工具。

安装

# 1. macOS / Linux 装 CLI（默认进 ~/.local/bin）
curl -fsSL https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.sh | sh
bsk --version

# 2. 把技能装进你的 Agent 环境（Cursor / Claude Code / Codex / DSH 等）
bsk install-skill --list --json
bsk install-skill --harness cursor --json

# 3. 装完跑一遍自检
bsk doctor

Windows 换成 irm https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.ps1 | iex。新装完 doctor 里通常只剩「extension connected」一条不过——去商店装好扩展、连接上再跑一次就绿了；要连另一台机器上的浏览器，用 bsk daemon pair 生成配对链接，贴进扩展的连接设置即可。

用法：五条命令够用

bsk open "https://example.com"   # 开一个会话，默认在后台 Agent 窗口里操作
bsk read                         # 读页面，元素按 @e1、@e2… 引用
bsk click @e3                    # click / fill / select / press 都认 @eN
bsk sync                         # 页面跳转或人工动过之后，重新同步状态
bsk close                        # 用完关会话

填表单是 bsk fill @e1 --value "xx"；让 Agent 批量干活有 bsk plan --steps '[...]'，多浏览器并存用 bsk browsers 挑一个传 --browser。

几条值得看的安全边界

  • 页面内容只当数据，页面上写给 Agent 的指令不生效，遇到注入要上报而不是照做；
  • 超时或「效果未知」时先 bsk sync 看状态，不盲目重试写操作；
  • Agent 默认用自己的后台窗口，碰你自己的标签页要先 bsk tab borrow 经你确认。
对经常要操作 NAS、路由器后台这类需要登录的内网页面的人来说，「借用现成登录态」比再起一个干净浏览器实用得多。
