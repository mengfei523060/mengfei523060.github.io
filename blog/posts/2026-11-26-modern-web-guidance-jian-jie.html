modern-web-guidance：Agent 的现代 Web 实践速查手册

编程2026-11-26

让 AI 写前端有个通病：模型记忆里的「最佳实践」是训练那会儿的——弹层还手撸 position: fixed、监听全局 click 关下拉、表单验证全靠 JS 兜圈子。可 Web 平台这两年进化很快，popover、<dialog>、anchor positioning、:has() 都已经是现货。modern-web-guidance 就是治这个的：Google Chrome 团队官方出的 Agent 技能，npm 包同名，作者里就有 Paul Irish 和 Ricky Viscomi。

它是什么

  • 200 多篇指南：按 html / css / js / forms / accessibility / performance / security / built-in-ai 等分类，从 :has() 选父元素、fluid scaling，到 passkey 登录、HTML 消毒、LCP / INP 调优都有；
  • 只查不写：它不生成代码，Agent 动手前先搜一篇对应指南，照着现代写法落地；
  • 零安装：一份 SKILL.md 加进技能目录，指南本体走 npx 现取（Node 22+），文档在 developer.chrome.com。

用法：三条命令

# 1. 搜：用 2–5 个英文词的「动词+对象」查询，命中返回 [{id, description}]
npx -y modern-web-guidance@latest search "light dismiss dialog"

# 2. 取：拿 id 换全文，可逗号传多个，这是写码前的依据
npx -y modern-web-guidance@latest retrieve "dialog,accessibility"

# 3. 扫：对整个目录找过时写法（约覆盖 20% 有确定性规则的指南）
npx -y modern-web-guidance@latest legacy-scan ./src --json

查询有讲究：一次只搜一个能力，responsive table dark mode 这种复合词要拆成两次；也别带框架名，它管的是平台本身，React / Vue 里照样用。

几个有意思的细节

  • 只信 Baseline Widely available：达标的特性直接用、不写降级，没达标的按指南给的 fallback 来，浏览器支持策略还可以写进 AGENTS.md 定制；
  • 用没用过要交底：SKILL.md 要求 Agent 交付时在末尾列一节「Modern Web Guidance」，说明哪条指南改变了实现——相当于自带引用出处；
  • 知道边界：搜不到就承认知不了，不硬凑不相干的指南；后端、CI、构建配置这些根本不在它的触发范围。
定位和上篇的 BrowserSkill 一路：都是给 Agent 外接「现查现用」的脑子。前端这块它补的是知识时效——模型负责写，它负责提醒：都 2026 了，这个别再手写。
