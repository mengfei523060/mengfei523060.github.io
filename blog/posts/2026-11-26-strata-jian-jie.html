Strata：把大 MoE 模型塞进家用电脑

编程2026-11-26

Strata 是个 MIT 协议的开源推理引擎，口号很直白：Run powerful AI on your own computer。它针对的是 Qwen3.8-Flash-Next 这类 MoE 大模型——本要在几百 GB 显存的服务器集群上跑，Strata 让它在「大内存 + 一张 12~24G 消费级显卡」的家用机上转起来。我之前那篇《本地 AI 主机配置》就是照着它攒的机。

核心思路：全机分工

MoE 模型的参数大头是一堆「专家」：Qwen3.8-Flash-Next 有 24,576 个专家，写每个词平均只用到 10 个——根本不需要全塞显存。Strata 的官方比喻是厨房：常用的放灶台，其余的在储物间。落到硬件上：

  • 显卡（显存）：每个词都要过的部分——注意力、路由、共享专家、输出头、KV Cache——外加一个热专家缓存，按对话内容自动学习该留谁，显存每多 1G 约多放 700 个专家；
  • 内存：全部专家常驻（pinned），显卡没有的专家由 CPU 就地计算，和显卡并行、互不等待；
  • SSD：放 28.8 GB 的查找表，每个词只读几行。

同一套引擎分别按 NVIDIA CUDA 和 AMD HIP 编译，A 卡 N 卡都支持。

速度从哪来

  • 先猜后验：模型自带的 MTP 小助手先猜几个词，大模型一次全体验收——答案仍是大模型定的，质量不变，出字快 1.6~1.8 倍；
  • 长文快读：文档一次读 8192 token，吃长文 / 代码库超 1000 token/s；多轮对话只增量读新内容，追问秒回；
  • 一个反直觉结论：显存容量比显卡算力更重要——显存里的专家每多一个，CPU 就少算一个。

安装与接入

# Linux / macOS 一行装
curl -fsSL https://github.com/Niko1221/Strata/releases/latest/download/install.sh -o install.sh && sh install.sh

strata launch    # 按提示选模型、下载、启动，自带 web 聊天窗口
strata connect   # 列出 Codex CLI / Claude Code 等工具的接入方法

Windows 有对应的 install.ps1，不想碰终端也有桌面 App（Win / Linux / Mac）。引擎对外提供 OpenAI / Anthropic 兼容 API，所以任何能自定义 API 的客户端都能接——我那个《Codex CLI 接入本地大模型》接的就是它。

硬件与模型怎么配

官方支持：NVIDIA RTX 20~50 系、AMD RX 7700~7900 / 9060 / 9070、Intel Arc（Linux）、Apple Silicon M1 起、Ryzen AI Max 等。模型按内存档位打包（如 Hy4-Flash 的 SQ-64/96/128 直接以内存大小命名），128 GB 内存是大 MoE 的甜点档；Qwen3.8-Flash-Next 推荐 ISTA-DASLab 压缩包，追求质量选 Unsloth 的 UD-Q4_K_XL。

至此本站的本地 AI 三件套齐了：Strata 负责跑模型，装机帖负责硬件账本，Codex 配置帖负责把模型接进日常工具——token 不再按个算钱。
