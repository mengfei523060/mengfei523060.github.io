我的 Linux 学习路线笔记

学习2026-11-24

零散学过很多次，这次给自己理一条按阶段走的路线，每阶段有明确目标和验收标准，学完打勾。

阶段一：日常使用与基础命令

  • 装一台虚拟机（Ubuntu Server 或 Debian），全程只用终端；
  • 文件与目录：ls cd cp mv rm mkdir find grep；
  • 查看与编辑：cat less head tail nano vim；
  • 权限：chmod chown、用户与组的概念；
  • 验收：能盲打完成「找文件 → 改内容 → 挪位置 → 设权限」整套操作。

阶段二：系统管理

  • systemctl 管理服务、journalctl 查日志；
  • apt / dpkg 装包与来源管理；
  • 磁盘：df du lsblk fdisk，挂载与 fstab；
  • 进程：ps top htop kill nice；
  • 验收：给自己的服务写一个 systemd unit，开机自启。

阶段三：网络

  • ip ss ping curl dig 排查连通性；
  • 防火墙 nftables/ufw、SSH 加固（密钥登录、禁密码）；
  • 反向代理 nginx 入门，配合内网服务做 HTTPS；
  • 验收：从外网安全访问家里的一项服务。

阶段四：Shell 与自动化

  • bash 变量、条件、循环、函数；
  • cron 定时任务、日志轮转 logrotate；
  • 用脚本把重复操作固化下来（备份、巡检、批量改名）；
  • 验收：至少三个在跑的自动化脚本。

常备资源

  • Arch Wiki —— 发行版无关的高质量文档；
  • Ubuntu 中文论坛 —— 中文环境问题基本都有答案；
  • man 与 tldr —— 手册与速查。
路线是死的，需求是活的：每次被现实问题卡住，就是最好的学习时机。
